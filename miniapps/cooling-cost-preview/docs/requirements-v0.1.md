# 냉방비 미리보기 요구사항 명세서

작성일: 2026-06-30  
문서 목적: 앱인토스 미니앱 **냉방비 미리보기**의 최신 인터랙티브 목업 기준 요구사항을 정의한다.

## 1. 서비스 개요

**냉방비 미리보기**는 원룸 1인 가구가 여름철 에어컨 사용으로 발생하는 냉방비를 직관적으로 추정하고, 이번 달 냉방비가 하루 단위로 얼마나 쌓이고 있는지 확인할 수 있게 돕는 토스 미니앱이다.

이전 기획은 사용자가 월 냉방비 예산을 먼저 정하고 잔여 예산을 확인하는 구조였으나, 실제 사용자는 전기세 예산을 미리 정해두고 에어컨을 사용하는 경우가 많지 않다. 따라서 최신 방향은 **예산 차감형**이 아니라 **누적 추정형**으로 변경한다.

핵심 질문:

> 오늘 에어컨을 이만큼 쓰면 이번 달 냉방비가 얼마나 쌓일까?

## 2. 핵심 문제

원룸 1인 가구에게 에어컨은 선택재가 아니라 필수재가 되었지만, 사용자는 에어컨 사용량이 실제 비용으로 얼마나 쌓이는지 실시간으로 체감하기 어렵다.

사용자는 보통 전기요금 고지서를 받은 뒤에야 비용을 인식한다. 이 앱은 고지서가 오기 전, 오늘 사용량과 지난 사용 패턴을 바탕으로 이번 달 냉방비 흐름을 미리 보여준다.

## 3. 타깃 사용자

| 항목 | 내용 |
| --- | --- |
| 핵심 타깃 | 원룸, 오피스텔, 고시원형 자취방에 거주하는 1인 가구 |
| 생활 패턴 | 집에 있는 시간이 길거나 밤에 에어컨 사용량이 많은 사용자 |
| Pain Point | 에어컨은 켜야 하지만 이번 달 냉방비가 얼마나 쌓이는지 모름 |
| 행동 특성 | 전기요금 고지서 수령 후에야 비용을 체감함 |
| 토스 적합성 | 생활비 확인, 고정비 감각, 월말 지출 예측 니즈가 있음 |

## 4. Value Proposition

원룸 1인 가구가 에어컨을 필요한 만큼 사용하면서도, 오늘 예상 냉방비와 이번 달 누적 사용 추정액을 바로 확인해 월말 냉방비 흐름을 미리 감지할 수 있게 한다.

짧은 표현:

> 에어컨을 참게 하는 앱이 아니라, 냉방비가 하루씩 얼마나 쌓이는지 보여주는 앱.

## 5. 제품 방향

### 5.1 최신 방향

- 월 냉방비 예산 입력을 받지 않는다.
- 잔여 예산, 예산 대비 사용률, 예산 상태 게이지를 제공하지 않는다.
- 이번 달 냉방비가 오늘을 포함해 얼마나 누적되었는지 보여준다.
- 오늘 포함 지난날의 요금 평균값을 기준으로 월말 예상 냉방비를 계산한다.
- 사용자가 매일 앱에서 오늘 사용량을 기록하면 이번 달 누적 사용 추정액이 갱신된다.

### 5.2 사용자가 얻는 가치

- 오늘 에어컨 사용이 비용으로 얼마인지 알 수 있다.
- 이번 달 냉방비가 현재까지 얼마나 쌓였는지 알 수 있다.
- 오늘까지의 평균 냉방비 흐름으로 월말 예상 금액을 가늠할 수 있다.
- 에어컨 사용을 죄책감보다 비용 감각으로 조절할 수 있다.

## 6. 주요 사용자 플로우

1. 첫 진입 화면에서 서비스 목적을 확인한다.
2. `시작하기` 버튼을 눌러 기본 환경 설정으로 이동한다.
3. 방 크기를 선택한다.
4. 에어컨 타입을 선택한다.
5. 최근 일주일간 하루 평균 에어컨 사용 시간을 입력한다.
6. 설정 완료 후 홈 화면으로 이동한다.
7. 홈 화면에서 오늘의 날씨, 기온, 습도를 확인한다.
8. 오늘 에어컨 사용 예정 시간을 슬라이더로 조절한다.
9. 사용 모드를 선택한다.
10. 오늘 예상 냉방비를 확인한다.
11. 이번 달 누적 사용 추정액과 월말 예상 금액을 확인한다.
12. `오늘 사용 기록에 반영` 버튼을 눌러 오늘 예상 냉방비를 누적액에 반영한다.
13. 필요하면 `되돌리기`로 방금 반영한 오늘 기록을 취소한다.

## 7. 화면 요구사항

### 7.1 화면 비율

- 목업은 모바일 앱 화면을 기준으로 한다.
- 화면 비율은 19.5:9에 가깝게 구성한다.
- 흰색 앱 화면 기준 약 `390 x 845` 비율을 따른다.

### 7.2 첫 진입 화면

첫 화면은 서비스 목적을 간단히 전달한다.

표시 요소:

- 서비스 아이콘
- 메인 문구: `오늘 에어컨 이만큼 써도 전기세 괜찮을까?`
- 보조 문구: `이번 달 냉방비가 얼마나 쌓이는지 알려드려요`
- CTA 버튼: `시작하기`

### 7.3 기본 환경 설정 화면

화면 제목:

- `기본 환경 설정`

입력 항목:

| 순서 | 항목 | 입력 방식 | 비고 |
| --- | --- | --- | --- |
| 1 | 방 크기 | 버튼 + 직접 입력 | `5평 이하`, `6~8평`, `9~12평`, `13평 이상`, `직접 입력` |
| 2 | 에어컨 타입 | 버튼 선택 | `벽걸이형`, `스탠드형`, `창문형`, `이동식`, `잘 모르겠어요` |
| 3 | 최근 일주일간 하루 평균 사용 시간 | 슬라이더 | 0시간~12시간+, 0.5시간 단위 |

방 크기 직접 입력:

- `직접 입력` 버튼을 누르면 평수 입력 필드가 노출된다.
- 사용자는 예: `8.5`처럼 소수점 1자리까지 입력할 수 있다.
- 입력값은 예상 냉방비 계산과 설정 요약에 즉시 반영된다.

최근 사용 시간 입력:

- 질문 문구: `최근 일주일간 하루 평균 몇 시간 트셨나요?`
- 보조 문구: `이번 달 누적 사용액을 추정하기 위해 필요해요.`
- 슬라이더 라벨: `0시간`, 현재 선택값, `12시간+`
- 해당 항목은 앞선 `에어컨 타입` 항목과 시각적으로 분리되도록 다른 문항보다 약간 더 큰 상단 간격을 둔다.

### 7.4 홈 화면

홈 화면은 상단 2/3의 오늘 냉방 확인 영역과 하단 1/3의 이번 달 누적 사용 추정 영역으로 구성한다.

#### 7.4.1 오늘의 날씨

표시 요소:

- 제목: `오늘의 날씨`
- 지역 선택 드롭다운
- 날씨 이모지
- 현재 기온
- 현재 습도
- 데이터 출처 또는 API 실패 시 목업값 표시

지역 선택:

- 전국 시도 단위 선택지를 제공한다.
- 선택지는 서울, 경기, 인천, 부산, 대구, 대전, 광주, 울산, 세종, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주를 포함한다.

#### 7.4.2 오늘 사용 시간

표시 요소:

- 제목: `오늘은 얼마나 켤까요?`
- 사용 예정 시간 숫자
- 0~12시간 슬라이더
- 슬라이더 눈금: 0, 4, 8, 12시간
- 오늘 예상 냉방비

입력 정책:

- 슬라이더는 0.5시간 단위로 조절한다.
- 슬라이더 조작 시 오늘 예상 냉방비가 즉시 갱신된다.

#### 7.4.3 사용 모드

선택지:

- 냉방
- 제습
- 취침

UI 정책:

- 이모티콘은 사용하지 않는다.
- 선택된 모드는 파란색 테두리와 연한 파란 배경으로 표시한다.

#### 7.4.4 사용 기록 반영

버튼:

- `오늘 사용 기록에 반영`
- `되돌리기`

동작:

- `오늘 사용 기록에 반영`을 누르면 현재 오늘 예상 냉방비가 이번 달 누적 사용 추정액에 반영된다.
- 같은 날 이미 반영한 상태에서 다시 누르면 중복 반영하지 않고 안내 토스트를 보여준다.
- `되돌리기`는 방금 반영한 오늘 기록만 취소한다.

#### 7.4.5 안내 문구

하단에 작은 크기와 옅은 색으로 안내 문구를 표시한다.

문구:

> 실제 전기요금은 누진제, 집 전체 사용량, 에어컨 소비전력, 설정 온도, 단열 상태에 따라 달라질 수 있어요. 이 결과는 냉방비 관리를 위한 참고용 예상 금액이에요.

### 7.5 이번 달 누적 사용 추정 카드

하단 영역은 월 예산이 아니라 누적 추정액을 중심으로 보여준다.

표시 요소:

- 제목: `이번 달 누적 사용 추정액`
- 누적 사용 추정액
- 보조 문구: `오늘 포함 지난날 평균 n원씩 쌓이고 있어요`
- 가로 바 그래프
- 현재 월 기준 경과일: 예: `11일째`
- 월말 예상 금액: 예: `이대로면 월말 약 78,000원`

시각화 정책:

- 이모티콘은 사용하지 않는다.
- 누적 흐름은 가로 바 그래프로 표현한다.
- 바의 채움 비율은 이번 달 날짜 진행률 기준으로 표시한다.
- 끝점은 회색 원형 dot으로 표시한다.

## 8. 계산 정책

### 8.1 냉방비 정의

앱에서 말하는 냉방비는 전기요금 전체가 아니라 **에어컨 추가 사용분, 즉 순수 냉방비 추정액**이다.

이유:

- 집마다 냉장고, PC, 조명 등 기본 전력 사용량이 다르다.
- 사용자의 핵심 질문은 전체 전기요금이 아니라 “에어컨을 켜면 얼마가 더 쌓이는가”이다.
- 순수 냉방비로 한정해야 사용자가 에어컨 사용과 비용 변화를 직관적으로 연결할 수 있다.

### 8.2 전기요금 계산 단순화

- 소비전력은 사용자가 직접 입력하지 않는다.
- 방 크기와 에어컨 타입을 바탕으로 시스템이 표준 소비전력값을 자동 매핑한다.
- 누진제는 상세 입력을 요구하지 않고 계산 상수에 간접 반영한다.
- 결과는 실제 청구액이 아니라 행동 판단을 위한 참고용 예상 금액이다.

### 8.3 에어컨 타입별 표준 소비전력

| 타입 | 표준 소비전력 |
| --- | --- |
| 벽걸이형 | 0.65kW |
| 스탠드형 | 1.8kW |
| 창문형 | 0.75kW |
| 이동식 | 0.9kW |
| 잘 모르겠어요 | 0.65kW |

### 8.4 사용 모드별 계수

| 모드 | 계수 |
| --- | --- |
| 냉방 | 1.00 |
| 제습 | 0.72 |
| 취침 | 0.58 |

### 8.5 방 크기 계수

방 크기는 다음 방식으로 비용에 반영한다.

```text
방 크기 계수 = 0.86 + (방 크기 / 10) * 0.18
```

직접 입력한 방 크기도 같은 산식에 적용한다.

### 8.6 날씨 계수

습도 계수:

- 습도 75% 이상: 1.08
- 습도 55% 이하: 0.96
- 그 외: 1.00

기온 계수:

- 33도 이상: 1.12
- 30도 이상: 1.04
- 그 외: 0.98

### 8.7 오늘 예상 냉방비

```text
예상 kWh = 에어컨 표준 소비전력 * 사용 시간 * 사용 모드 계수 * 방 크기 계수 * 습도 계수 * 기온 계수

오늘 예상 냉방비 = 예상 kWh * 260원
```

### 8.8 초기 누적 사용 추정액

신규 사용자는 앱 기록이 없으므로 최근 일주일간 하루 평균 사용 시간을 입력한다.

```text
초기 누적 사용 추정액 = 최근 일주일 하루 평균 사용 시간 기준 냉방비 * 이번 달 어제까지의 경과일 수
```

예:

- 오늘이 6월 30일이면 어제까지의 경과일 수는 29일이다.
- 최근 평균 사용 시간 기준 하루 냉방비가 2,000원이라면 초기 누적 사용 추정액은 58,000원이다.

### 8.9 오늘 포함 누적 사용 추정액

홈 화면에서 표시하는 이번 달 누적 사용 추정액은 오늘을 포함한다.

```text
오늘 포함 누적 사용 추정액 = 어제까지의 추정 누적액 + 오늘 예상 냉방비
```

단, 사용자가 `오늘 사용 기록에 반영`을 이미 누른 경우 오늘 예상 냉방비가 중복으로 더해지지 않도록 한다.

### 8.10 오늘 포함 지난날 평균

```text
오늘 포함 지난날 평균 = 오늘 포함 누적 사용 추정액 / 오늘 날짜 수
```

예:

- 오늘이 11일이고 오늘 포함 누적 사용 추정액이 28,500원이라면
- 하루 평균은 약 2,590원이다.

### 8.11 월말 예상 금액

```text
월말 예상 금액 = 오늘 포함 지난날 평균 * 이번 달 총 일수
```

이 값은 “이대로면 월말 약 n원”으로 표시한다.

### 8.12 가로 바 그래프

가로 바 그래프는 금액 대비 비율이 아니라 이번 달 날짜 진행률을 기준으로 표시한다.

```text
그래프 채움 비율 = 오늘 날짜 수 / 이번 달 총 일수
```

예:

- 30일 중 11일째라면 채움 비율은 약 36.7%이다.

## 9. 데이터 및 API

### 9.1 날씨 API

날씨 정보는 외부 API를 통해 가져온다.

현재 목업 기준:

- Open-Meteo API
- 현재 기온
- 현재 습도
- 날씨 코드 기반 날씨 텍스트

API 실패 시:

- 지역별 fallback 목업값을 사용한다.

## 12. 수용 기준

1. 사용자는 월 예산을 입력하지 않고도 기본 환경 설정을 완료할 수 있어야 한다.
2. 방 크기에서 `직접 입력`을 선택하면 숫자 입력 필드가 노출되어야 한다.
3. 직접 입력한 방 크기는 오늘 예상 냉방비 계산에 반영되어야 한다.
4. 최근 일주일 평균 사용 시간은 기본 환경 설정의 세 번째 문항으로 제공되어야 한다.
5. 설정 완료 시 최근 평균 사용 시간을 기준으로 어제까지의 이번 달 누적 사용 추정액이 계산되어야 한다.
6. 홈 화면의 이번 달 누적 사용 추정액은 오늘 예상 냉방비를 포함해 보여야 한다.
7. `오늘 사용 기록에 반영` 후에는 오늘 예상 냉방비가 중복 반영되지 않아야 한다.
8. `되돌리기`는 방금 반영한 오늘 기록만 취소해야 한다.
9. 하단 카드에는 잔여 예산과 예산 대비 사용률이 표시되지 않아야 한다.
10. 하단 카드에는 누적 사용 추정액, 하루 평균 누적액, 월말 예상 금액, 가로 바 그래프가 표시되어야 한다.

## 브라우저 흐름

가상 시계는 2026-10-16, 브라우저 시간대는 America/Los_Angeles로 설정하여 표시 날짜가 한국 시간을 따르는지 확인했다. 날씨 실패·지연·지역 변경을 안정적으로 재현하기 위해 제어한 응답을 사용했다.

1. 설정 입력 검증, 키보드 슬라이더 조작, 새로고침 후 입력 복원, 저장·교체·0시간 취소·재저장, 설정 변경 후 과거 기록 유지.
2. 새 브라우저 컨텍스트에서 기존 저장본 복원, 앱을 열어둔 채 한국 날짜·월 전환, 이전 월 목록 유지.
3. 날씨 통신 실패·잘못된 응답·시간 초과 시 예시값 표시, 같은 지역 최근 성공값 사용 시 캐시 표시.
4. 이전 지역의 응답이 늦게 도착해도 새 지역 날씨·기록을 덮어쓰지 않음.
5. 손상 데이터 보존·별도 백업 후 초기화, 저장소 접근 거부·공간 부족 시 복구 화면과 마지막 저장본 유지.
6. 두 탭에서 변경 충돌 안내 후 최신 데이터 재조회.

화면 폭 **320px, 390px, 1280px**에서 오늘 화면의 가로 넘침을 검사했다. 설정과 기록 목록의 이름 있는 입력·버튼·슬라이더를 실제로 조작했다. 화면 이미지는 [오늘](../assets/home-390.png), [기록](../assets/history-390.png), [복구](../assets/recovery-390.png)에 보관한다. 기계 판독 결과는 [browser-results.json](browser-results.json)이다.

실제 외부 API도 별도로 조회했다. 2026-10-16 16:47 한국 시간에 개선된 `fetchWeather` 함수로 서울 응답(21.6°C, 습도 65%, 맑음, 관측 기준 16:45)을 읽고 유효성 검사를 통과했다. 재현용 화면의 고정 응답과 실제 조회값은 구분한다.

## 확인의 한계

- 실제 토스앱·모바일 기기·신규 `.ait` 패키지 생성·토스 심사는 검증하지 않았다.
- 기존 SDK 2.10.1 전이 의존성에 React Native·navigation peer 경고가 있다. 브라우저 검사·빌드는 통과했으며, 토스 모드의 기기 호환성을 뜻하지 않는다.
- 실측 소비전력·실제 청구요금과의 정확도 검증을 수행하지 않았다. 산식은 원본의 가정 기반 비교 모델이다.
- localStorage의 저장 한도·브라우저 정책과 삭제에 영향을 받는다. 변경 충돌 감지는 제공하지만 동시 쓰기의 완전한 트랜잭션을 제공하지 않으므로 한 탭 사용을 권장한다.

원본 18개 파일과 기존 AIT의 해시를 보존 기록과 대조했다. 원본 PC 폴더의 소스는 수정하지 않았다.
